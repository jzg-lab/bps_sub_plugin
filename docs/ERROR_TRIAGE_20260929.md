**可选修复：** 在上传附件或发送 BPS 前识别工具结果中的图片，将这类原始请求

## 2. non_sse：本窗口均为真实 HTTP 错误

| 最终端点 | 状态与数量 | 已知原因/边界 |
| --- | --- | --- |
| BPS | 403：40 | 同一通用 JSON 错误 `403: Forbidden.`，`type=server_error`；不能据此确定 RPM、工作区或风控原因 |
| BPS | 429：1 | 明确 `type=usage_limit_reached`、`The usage limit has been reached`，不是本窗口中出现了“1000 RPM”提示 |
| BPS | 503：1 | `Upstream OpenAI API request failed.`，没有进一步可确定的根因 |
| Codex | 429：30；503：10；401：3 | 原生路径的 HTTP 错误，不能归给 BPS；本次未确认每条的具体上游拒绝原因 |
| Codex | 400：10 | 均为 `gpt-5.4`；对应宿主日志归类 `upstream_400_codex_plan_gated_model` |

10 次 Codex 400 出现在北京时间 01:20 至 02:50，每十分钟一次。
宿主为这些模型/账号设置约 30 分钟冷却。这说明至少有一类冷却由模型套餐不支持触发，
不能把所有“临时不可调度”归因于高并发。**定时探测/固定任务是线索，不是已证实来源。**
下一步应定位发起该周期请求的客户端或探测配置，再选择已支持的测试模型或修正路由；
本次不擅自更换用户模型，也不移除冷却。

普通 403 仍缺少作用域证据。需要部署后利用
[0.6.5 被动诊断](LIMIT_DIAGNOSTICS.md)关联实际发送时间、脱敏身份、错误类型、
响应头及本地 inflight。并发上限不等于每分钟请求上限，不能先假定降并发能修复它。

## 3. unknown_tool：需要区分协议与工具范围

9 条中：

- relay 模式 4 条：3 条原始内层 JSON 存在转义/分隔符问题；
  另 1 条内层 JSON 有效，但 `exec_command` 不在该请求声明的工具目录里。
- native 模式 5 条：`list_skills` 3 次、`update_plan` 1 次、`run_officejs` 1 次，
  均未在对应客户端请求里声明；不是仅因面板不认识合法客户端工具而产生的误报。
- 8/9 在相同旧 session/cache 标识下随后有 `tool_call` 记录。
  这提示后续流程可能继续，但旧 session 字段不严格代表真实会话，
  不能据此证明同一动作最终执行成功。

`internal/basispoints/relay.go` 已含非法反斜杠、引号兼容处理及工具 schema 校验。
看到原始 JSON 非法不能单独证明是解析器的最终失败点：还可能是目录查找或参数校验。
进一步修复前需用脱敏回归用例确定具体拒绝阶段。

**可修方向：** 加强 native 模式的可用工具约束；为 relay 拒绝记录明确阶段
（外层解析、内层解析、未声明工具、参数校验）；保留失败后的重试指引。
不要自动把 `exec_command` 映射为 `exec`，不要执行未声明工具或猜修后的 shell 命令。

## 4. error / failed / cancelled：不能混作连接失败

- `error=8`：6 次 `unexpected EOF`、1 次等待响应头超时、1 次请求阶段 EOF。
  5 次在原生 Codex，3 次在 BPS。响应头超时已为 **300 秒**，不是旧 30 秒配置。
- 中断耗时有约 901 秒和 1770 秒的重复值；可作为检查代理/上游连接寿命的线索，
  不能仅凭耗时定位责任层。应关联首字节、终态和断开方，区分建连失败与流中途断开。
- 另有 1 次 BPS 代理建连失败触发回落，最终 Codex 为 200/text；
  它属于前述 132 次回落，不应重复计入 8 次 error。
- `failed=6`：均为原生 Codex 的 HTTP 200 流内失败，内容为
  `Our servers are currently overloaded. Please try again later.`。本地格式修复不能解决上游过载。
- `cancelled=148`：只能确认终态前取消，不能全部断言正常，也不能全部算故障；
  需客户端/宿主取消原因才能区分用户停止、请求替换、超时和其他中断。

有些错误发生时已经发送部分文本或工具结果，不能无条件重放整轮请求，
否则可能造成重复输出、重复工具执行和额外费用。
